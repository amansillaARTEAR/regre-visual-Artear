Configurar acceso

Este dashboard corre 100% en tu navegador (GitHub Pages no tiene backend), así que necesita un token de GitHub para poder disparar workflows y leer los reportes de un repo privado. El token se guarda únicamente en el localStorage de tu navegador — nunca sale de acá salvo hacia api.github.com.

Crealo en GitHub → Settings → Developer settings → Fine-grained tokens, con acceso limitado a solo este repositorio (regre-visual-artear) y permisos: Actions: Read and write, Contents: Read and write. Sin esos dos permisos el dashboard no puede disparar corridas ni leer los reportes.

Disparar regresión

Usa la misma versión, modo y tolerancia de arriba, y corre las URLs completas de cada producto (la selección de URLs de arriba no aplica acá — es sólo para un producto puntual).

Limpieza de artifacts

Corre semanalmente sola (domingos 06:00 UTC) y borra artifacts viejos de Actions para no llenar el storage. Desde acá podés dispararla manualmente cuando quieras.
